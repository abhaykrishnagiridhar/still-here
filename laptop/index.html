A rover for a room you can't see into. It finds the light, works out which blocks are safe to lift, and clears a path to whoever is underneath.

Take control → Autonomous mode

Both modes open a status page for now. The rover link is still being built.

How it works

  1. Find

    The camera picks out the pulsing light, the blocks and where they sit, and any source of heat.

  2. Choose

    The operator taps the survivor on the screen.

  3. Plan

    The blocks are put in order: top ones first, and the ones holding others up left alone. The plan is shown before anything moves.

  4. Act

    The arm lifts the blocks away one at a time. The approved plan is stored on the rover.

  5. Adapt

    If a block shifts, the plan is redone. A heavy or load-bearing block is left in place and the path goes around it. If the operator link drops, the rover finishes the stored plan on its own and says so on screen.

  6. Finish

    The path is clear, the light keeps pulsing, and the screen shows a safe-path report.

Status: perception and planning are in progress, and the rover is not connected yet. The first thing being tested is lifting the top block off a two-block stack without moving the one underneath.
